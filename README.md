# Sales Data Analysis using Excel

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel.

The project includes data cleaning, Pivot Table analysis, chart creation,
and an interactive Excel dashboard to understand sales performance,
product quantity, regional revenue, customer ratings, and sales trends
over time.

## Tools Used

- Microsoft Excel
- Excel Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset

The dataset contains sales-related information including:

- Date
- ID
- Name
- Region
- Rating
- Product
- Designation
- Location
- Quantity
- Price Per Unit
- Sales Revenue

## Data Analysis Process

The project followed these steps:

1. Imported the sales dataset into Microsoft Excel.
2. Reviewed and cleaned the data.
3. Organized the sales data for analysis.
4. Created Pivot Tables to summarize the data.
5. Created Pivot Charts to visualize the analysis.
6. Added slicers for interactive filtering.
7. Designed an Excel dashboard to present the results.

## Pivot Table Analysis

The following Pivot Tables were created:

### 1. Total Revenue by Customer

Analyzed the total sales revenue generated by each customer.

### 2. Total Quantity Sold by Product

Analyzed the quantity of products sold across different products.

### 3. Rating Distribution by Region

Analyzed the distribution of customer ratings across different regions.

### 4. Total Sales Revenue by Region

Compared total sales revenue across different regions.

### 5. Sales Revenue Trend Over Time

Analyzed sales revenue across different years to identify changes
in sales performance over time.

## Dashboard

The Excel dashboard contains the following visualizations:

- Total Revenue by Customer
- Total Quantity Sold by Product
- Sales Revenue Trend Over Time
- Rating Distribution by Region
- Total Sales Revenue by Region

### Interactive Slicers

The dashboard includes slicers for:

- Region
- Rating
- Product
- Designation

These slicers allow the dashboard visuals to be filtered interactively.
